# uv-emitter v0.2 — fabrication files

Gerbers and drill files as released on 2024-04-06, generated by KiCad 8.0.0-8.0.0-1~ubuntu22.04.1.
They are unmodified copies of the files from the original `uv-water` repository.

The matching design is the git tag **`uv-emitter/v0.2`**: `git checkout uv-emitter/v0.2` and open
`hardware/uv-emitter/uv-emitter.kicad_pcb`.

| File | What it is |
|---|---|
| `gerbers/` | Gerber layers, Excellon drill file and Gerber job file |
| `UV-LED-source.pdf` | schematic PDF exported at release time |

## Verification

Regenerating the gerbers and drill file from the `uv-emitter/v0.2` board with kicad-cli 8.0.6
reproduces the copper, mask, paste, silkscreen, board-outline and drill geometry of these
files. The comparison was done at 1 µm resolution and ignored header metadata, aperture
numbering and drawing order.
