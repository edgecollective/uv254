# uv-control v0.1 — fabrication files

Gerbers and drill files as released on 2024-07-29, generated by KiCad 8.0.0-8.0.0-1~ubuntu22.04.1.
They are unmodified copies of the files from the original `uv-water` repository.

The matching design is the git tag **`uv-control/v0.1`**: `git checkout uv-control/v0.1` and open
`hardware/uv-control/uv-control.kicad_pcb`.

| File | What it is |
|---|---|
| `gerbers/` | Gerber layers, Excellon drill file and Gerber job file |
| `UV-Control.csv` | BOM exported from Pcbnew (checked against the board: references, footprints and values match) |
| `uv_control_v0p1_ibom.html` | interactive HTML BOM (InteractiveHtmlBom) |

## Verification

Regenerating the gerbers and drill file from the `uv-control/v0.1` board with kicad-cli 8.0.6
reproduces the copper, mask, paste, silkscreen, board-outline and drill geometry of these
files. The comparison was done at 1 µm resolution and ignored header metadata, aperture
numbering and drawing order.
The only difference is a 1 nm vertex split in one silkscreen logo polygon (rounding).
