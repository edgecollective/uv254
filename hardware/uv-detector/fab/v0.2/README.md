# uv-detector v0.2 — fabrication files

Gerbers and drill files as released on 2024-04-06, generated by KiCad 8.0.0-8.0.0-1~ubuntu22.04.1.
They are unmodified copies of the files from the original `uv-water` repository.

The matching design is the git tag **`uv-detector/v0.2`**: `git checkout uv-detector/v0.2` and open
`hardware/uv-detector/uv-detector.kicad_pcb`.

| File | What it is |
|---|---|
| `gerbers/` | Gerber layers, Excellon drill file and Gerber job file |
| `UV-Detector-v0.2.pdf` | schematic PDF exported at release time |

## Verification

Regenerating the gerbers and drill file from the `uv-detector/v0.2` board with kicad-cli 8.0.6
reproduces the copper, mask, paste, silkscreen, board-outline and drill geometry of these
files. The comparison was done at 1 µm resolution and ignored header metadata, aperture
numbering and drawing order.

**Known difference:** The fabricated gerbers also carry the copper text "uva-detect-v0.2" on F.Cu (x 10-28.5 mm, y 38-39 mm), which was deleted from the board before it was committed. Everything else regenerates identically.
