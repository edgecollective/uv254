# uv-detector v0.3 — fabrication files

Gerbers and drill files as released on 2024-08-19, generated by KiCad 8.0.0-8.0.0-1~ubuntu22.04.1.
They are unmodified copies of the files from the original `uv-water` repository.

The matching design is the git tag **`uv-detector/v0.3`**: `git checkout uv-detector/v0.3` and open
`hardware/uv-detector/uv-detector.kicad_pcb`.

| File | What it is |
|---|---|
| `gerbers/` | Gerber layers, Excellon drill file and Gerber job file |
| `UV-Detector.csv` | BOM exported from Pcbnew (checked against the board: references, footprints and values match) |
| `uv_detector_v0p3_ibom.html` | interactive HTML BOM (InteractiveHtmlBom) |

## Verification

Regenerating the gerbers and drill file from the `uv-detector/v0.3` board with kicad-cli 8.0.6
reproduces the copper, mask, paste, silkscreen, board-outline and drill geometry of these
files. The comparison was done at 1 µm resolution and ignored header metadata, aperture
numbering and drawing order.
The only difference is a 1 nm vertex split in one silkscreen logo polygon (rounding).
