uv254

Open hardware for the uv254 UV water-quality sensor, by Edge Collective. It is three boards: a UV-C LED, a UV-C photodiode, and a controller that drives one and reads the other.

UV-Control

nRF52840 controller, ADS1115 ADC, colour display, microSD, buttons

UV-Emitter

Inolux IN-C35PPCTGU0 UV-C LED and its driver

UV-Detector

SD008-2171-112 UV-C photodiode with an op-amp front end
